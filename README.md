# Laravel React E-Commerce

An e-commerce web application built with Laravel, React, and Inertia.js as a solo developer portfolio project.

## Current Status

The project is currently in the initial setup phase with the base application structure initialized. Features, architecture details, and setup steps will be documented progressively as development advances.

## Planned Stack

- **Backend:** Laravel
- **Frontend:** React, Inertia.js
- **Database:** SQLite
